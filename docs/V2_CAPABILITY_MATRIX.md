# V2 Capability Matrix

## Green inside this codebase
- Modern responsive navigation and discovery UI
- Catalog data model
- Search/category filtering
- Creator profiles/data architecture
- Favorites/history/playlists schema
- Creator Studio submission flow
- Rights-gated publishing logic
- Performer verification/consent records
- Moderation/report/takedown schema
- Admin command-center architecture
- Purchases/subscriptions/payout ledger schema
- Analytics-ready event/history data model
- System status center
- Demo/fallback catalog so the UI is testable before Supabase configuration

## Integration-ready, but cannot be truthfully marked Live without provider setup
- Video object storage
- Transcoding / adaptive streaming
- Global CDN
- Identity/age verification
- Payment processing
- Email/SMS
- High-scale recommendation/ML service
- Production content moderation providers

The System Status screen is intentionally designed to show LIVE only after configuration.
