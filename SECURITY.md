# Security policy

This package is a defensive prototype. It does not contain exploit, credential
bypass, retaliation, covert surveillance, or destructive automation features.

Production deployments must use independently reviewed backend services,
hardware-backed keys, least privilege, signed releases, encrypted transport,
tamper-evident audit storage, explicit device ownership or authorization, and
documented incident-response procedures.

Report security concerns privately to the designated 999 Intelligence security
contact before public disclosure.
